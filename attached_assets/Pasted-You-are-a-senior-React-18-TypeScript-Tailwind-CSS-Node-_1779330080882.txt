────────────────────────

5. The code must be printable.
6. The code must be scannable later to retrieve the item details.

Suggested fields in items table:

- qr_code_value

- barcode_print_count

Code format example:

or

Rules:
- Do not reuse barcode/QR code for another item.
- Do not overwrite existing barcode/QR code unless Super Admin explicitly regenerates it.
- If an old item has no barcode, generate one safely.
- Bulk import must generate barcode/QR code for every valid imported item.
- Duplicate/invalid rows must not generate barcode/QR code.
