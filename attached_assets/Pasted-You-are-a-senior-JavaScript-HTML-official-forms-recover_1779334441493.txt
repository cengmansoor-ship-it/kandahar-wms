────────────────────────
FORWARD-ONLY SYNCHRONIZATION RULE
────────────────────────

Restore forward-only cascading sync exactly.

Core rule:
Data moves only forward.
Data must never move backward.

When a form is saved:
- current form saves its own data
- shared fields move only to forms after it
- previous forms must never change

Mandatory guard:

if (targetIndex <= sourceIndex) {
  return;
}

Expected behavior:

Saving Proposal:
- updates Tender, Comparison, Purchase Order, Receipt Report, SI9, FS5
- does not damage Proposal

Saving Tender:
- updates Comparison, Purchase Order, Receipt Report, SI9, FS5
- never updates Proposal

Saving Comparison:
- updates Purchase Order, Receipt Report, SI9, FS5
- never updates Proposal or Tender

Saving Purchase Order:
- updates Receipt Report, SI9, FS5
- never updates Proposal, Tender, Comparison

Saving Receipt Report:
- updates SI9 and FS5 only

Saving SI9:
- updates FS5 only

Saving FS5:
- saves itself only
- updates no previous form

Example:
Proposal quantity = 4, save:
Proposal remains 4
Tender, Comparison, Purchase Order, Receipt Report, SI9, FS5 become 4

Tender quantity = 3, save:
Proposal remains 4
Tender becomes 3
Comparison, Purchase Order, Receipt Report, SI9, FS5 become 3

Comparison quantity = 1, save:
Proposal remains 4
Tender remains 3
Comparison becomes 1
Purchase Order, Receipt Report, SI9, FS5 become 1
